# FIA Motorsport Sim

Браузерный симулятор гонок WEC/GT3 и Formula 1 с процедурным 3D-рендером,
физикой шин, квалификацией, пит-стопами и сезоном.

## Запуск

Игра не требует сборки. Откройте опубликованную страницу GitHub Pages либо
запустите локальный HTTP-сервер в каталоге проекта:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Управление

- `W / S` — газ и тормоз;
- `A / D` — поворот;
- `V` — переключение камеры;
- `H` — гоночная траектория;
- `M` — звук;
- `Esc` — пауза.
